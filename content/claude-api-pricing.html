Claude API Pricing (2026): Token Rates, Caching & Batch Discounts

Checked September 4, 2026 · By Jason Zhu

As of September 4, 2026, Anthropic's first-party Claude API is quoted in USD per MTok (one million tokens), and standard input rates range from $1 per million input tokens and $5 per million output tokens for Claude Haiku 4.5 up to $10 per million input tokens and $50 per million output tokens for Claude Fable 5.1. Batch processing cuts standard token prices by 50% for asynchronous workloads, and prompt caching has separate write and read pricing. For teams routing through a gateway, ApiFlux advertises Claude Sonnet 5 at $1.70 input / $8.50 output per MTok — 85% of Anthropic's list price — though that is a vendor-published claim, not an independently audited rate. Prices are time-sensitive; recheck Anthropic's live pricing before committing to a budget.

At a glance: Claude API pricing is usage-based · Input and output tokens have separate rates (output is more expensive) · Haiku 4.5 has the lowest listed standard rate · Sonnet 5 is a general-purpose candidate ($2/$10 now standard) · Batch API cuts standard rates by 50% for async work · Prompt caching helps only when stable prefixes are reused · ApiFlux advertises 85% of list price (Sonnet 5 at $1.70/$8.50) and a $1 starting credit — vendor-published claims.

Prompt caching costs

Prompt caching reduces the cost of repeatedly sending the same prompt prefix. Anthropic's prompt caching documentation lists these standard multipliers relative to base input price:

Cache operationPricing multiplierMeaning
5-minute cache write1.25×Cache valid for 5 minutes
1-hour cache write2×Cache valid for 1 hour
Cache read (hit)0.1×Applies to a cache hit

Source: Anthropic prompt caching documentation, checked September 4, 2026.

Anthropic's current pricing table lists Claude Fable 5.1 cache hits and refreshes at $0.25 per MTok, or 0.025× its $10 base input rate. Because cache pricing is model-specific and time-sensitive, recheck the model-specific table before publication.

A 5-minute write pays off after one successful cache read (1.25× write vs. a second full 1× input); a 1-hour write pays off after two reads (2× vs. three 1× inputs).

Note: Batch, caching, and data-residency modifiers can interact, but they do not make the total bill automatically predictable. Calculate each token category separately and confirm the selected model and platform's billing rules.

Most batches finish in under an hour; a batch is limited to 100,000 requests or 256 MB, must complete within 24 hours, and results are downloadable for 29 days. Results are not guaranteed to preserve input order; streaming, fast mode, and max_tokens: 0 are not supported. Use unique custom_id values. Claude API pricing vs Claude subscription pricing

The Claude API is pay-as-you-go: you are billed for the tokens and features your application uses. It is not a prepaid bundle of a consumer or team subscription, and a subscription should not be treated as prepaid API credits.

OptionBilling modelBest for
Claude APIPer-MTok token usage + feature feesApplications, services, automation, integrations
Claude ProMonthly subscription with usage limitsIndividual users
Claude MaxHigher-tier subscription with higher limitsHigh-frequency individual users
Team / EnterpriseTeam subscriptions with seatsOrganizations
Claude Code + ConsoleDepends on Console/API billing pathDevelopment teams

Separate Claude consumer or team plans buy product access, not API capacity. If you are building an application, plan for API token costs, spend limits, and rate limits separately from any Claude subscription you hold.

Claude API pricing FAQ

  1. Is Claude API pricing monthly or pay-as-you-go? Usage-based; depends on token usage and features, not a fixed API subscription price.
  2. What does MTok mean? One million tokens; input and output are priced separately by model.
  3. What is the cheapest Claude API model? Haiku 4.5 at $1/$5 per MTok — but production cost depends on success, retries, latency, and review.
  4. Why is Sonnet 5 priced at $2/$10? The September 1, 2026 increase to $3/$15 was canceled; $2/$10 is now standard.
  5. Does the Claude API have a free tier? Anthropic's documentation does not establish a permanent free API tier in the sources reviewed; check current Console billing docs. (ApiFlux separately advertises a $1 starting credit — a vendor claim.)
  6. Can prompt caching reduce the bill? Yes, for eligible stable prefixes with cache hits within the TTL; not for output, variable input, or every request.
  7. How much cheaper is the Message Batches API? 50% off standard token pricing, asynchronous.
  8. How is Claude Code billed? It can be used through subscription plans or a Claude Console/API account. When using a Console account or API key, usage may be billed at these API rates; subscription plans have their own terms. For endpoint setup through a gateway, see the ApiFlux Claude Code docs.
  9. Does a gateway change Anthropic's prices? It may add fees or markup; confirm separately. ApiFlux is a routing option, not proof of lower underlying rates.
  10. Are prices the same on Bedrock and Vertex AI? Not necessarily; compare each platform's own official documentation.
