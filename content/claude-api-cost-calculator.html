Method: base input cost = requests × input tokens ÷ 1,000,000 × input rate; base output cost likewise. Cached input is charged as a cache write (1.25× input for a 5-minute TTL) plus a cache read (0.1× input for most models; Fable 5.1 at 0.025×). Batch applies a 50% discount to input and output token charges. Retry rate scales token cost; ApiFlux estimate applies its vendor-published 85%-of-list rates. Tool tokens and web-search fees are added. Cost per accepted result = total cost ÷ (requests × accepted-result rate). Web-search fees are modeled using Anthropic published rate; gateway-specific fees may differ. This does not include taxes, negotiated terms, server-tool execution fees, or platform-specific billing.
