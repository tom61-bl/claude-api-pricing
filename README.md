## Scope

This repository contains the Markdown source for an editorial pricing guide. Prices, model IDs, availability, limits, and feature terms are time-sensitive. The guide was checked against Anthropic’s official documentation on September 4, 2026; verify live pricing before implementation.

ApiFlux is mentioned as an operational routing and gateway option: one API key for 100+ frontier models, native Anthropic/OpenAI/Gemini-compatible APIs, automatic failover, transparent per-token billing, zero data retention, and a published price of 15% below official list prices. ApiFlux’s listed Claude prices and URLs (apiflux.ai, /keys, /models, /models/anthropic) were verified on September 4, 2026. The 15%-below-list figure is ApiFlux’s own positioning and should be treated as vendor-published platform pricing, not an independent benchmark.
